검색 서버 연결

GitHub Pages에서 실제 공고를 가져오려면 검색 서버가 필요합니다. 아래 버튼으로 서버를 만들거나, 이미 배포한 모아잡 주소를 연결하세요.

검색 서버 만들기 · Render ↗

Render에서는 무료 Free 항목을 선택하세요. 무료 서버는 잠든 뒤 첫 연결에 약 1분이 걸릴 수 있습니다. 서버 주소는 이 브라우저에 저장됩니다.

데이터 백업

관심 공고와 메모는 현재 브라우저에 저장됩니다. 다른 기기로 옮기거나 보관하려면 아래의 내보내기를 사용하세요.

상세 필터 지역·경력·학력·급여·키워드

필터는 지금까지 가져온 목록에 적용됩니다. 페이지 번호 옆의 더보기 >>로 5페이지씩 범위를 넓힐 수 있습니다. 목록에 없는 정보는 미기재로 표시하며, 급여 협의는 연봉 미기재로 처리합니다.
